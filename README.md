# 📚 Library Management System

A simple Library Management System built using Python.

* Add books
* Show available books
* Search books
* Borrow books
* Return books

## Technologies Used

* Python

1. Install Python.
2. Download this repository.
3. Open the project folder in the terminal.
4. Run:

```bash
python "📚 Project 4 . Library Management System.py"
```
